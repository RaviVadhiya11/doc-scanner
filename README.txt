DOC SCANNER - GITHUB PAGES PACKAGE

Files:
- index.html: app screen and features
- manifest.webmanifest: PWA metadata
- sw.js: basic offline shell cache
- icons/: PWA icons

GitHub Pages:
1. Create a NEW public repository named doc-scanner.
2. Upload all files and folders from this ZIP to the repository root.
3. Repository Settings > Pages > Deploy from a branch > main > /(root) > Save.
4. Wait for the Pages URL: https://YOUR-USERNAME.github.io/doc-scanner/
5. Open the URL on Android Chrome and test.

Important:
- Some tools load third-party libraries from CDNs and need internet.
- PDF compression is not implemented as true compression.
- This starter app is not yet guaranteed to meet Google Play policy or production quality.
- Before Play Store release, test every feature, prepare privacy policy and complete Data safety accurately.
